# Loam 0.5.2 — استعادة الواجهة الأصلية

المرجع: صورة المستخدم والنسخة الأصلية المثبتة. استُعيدت قواعد الواجهة الأصلية في ui/restore-command.css بدل إعادة تأليف تصميم مشابه.

- شريط جانبي332بكسل: مسار أيقونات62 ولوحة مهام270، وأيقونات التنقل الأصلية، والبحث وحالات المهام واختيار النموذج.
- شريط حالة54بكسل، منطقة رئيسية بعرض أقصى1260، العنوان والتوهج الأصليان، ومربع طلب بأقسامه الأصلية: روابط السياق وشريط الأنماط والطلب والإرسال.
- ست بطاقات بنفس ترتيب الفئات وشبكة3أعمدة والأيقونات الملونة والوصف والتذييل. حلت مسمياتLoam محل الأسماء الأخرى، وربطت البطاقات بالأنماط الفعلية دون الادعاء بخدمات غير متاحة.
- لوحة الألوان الأصلية الفعلية للنمط العام: hue268 وhue2=215، مثبتة من بيانات النسخة الأصلية. الخطوط Readex Pro وTajawal وJetBrains Mono مضمّنة محليًا مع تراخيصOFL.
- حافظت الأنماط السبعة على صفحاتها وأدواتها، وحافظت كل مهمة على معرفها وملفاتها المعزولة. يبقى تغيير عدد المهام أو محتواها أو النمط المحدد اختلافًا طبيعيًا في البيانات المعروضة.

## التحقق

نجحت اختبارات TypeScript والترميز والواجهة والصفحات الفرعية وعزلHTTP. غطى فحص الواجهة البحث واختصارCtrl+K والطي والمظهر وتمرير الطلب والأنماط والصلاحيات والمرفقات والحالات والاستئناف و320/768/1440 وRTL/LTR وتكبير200%. أضيفت لقطة1900×980 مع التحقق من عرض الشريط332 وثلاثة أعمدة وتحميل الخط المحلي، وفُحصت بصريًا مقابل المرجع.

نجح مسار Edge الفعلي مع المصدر والحزمة: رفع ملف داخل مهمة، تنفيذ أداة، حفظ الناتج، ثم مهمة جديدة بلا ملفات السابقة. graphify update . خرج1 بلا تقرير؛ لم يُستخدمTestSprite غير المثبت.
