# إصلاح تكامل الخدمات — Loam 0.5.5

## التغييرات

- صفحة «الخدمات ← التكاملات» تعرض أدوات MCP والجسور المتخصصة (Frontier وMiroFish وRork) ووصفها ومدخلاتها.
- اختيار مهمة وتفعيل أدوات محددة ثم حفظها يجعلها متاحة للمساعد عبر `integration_list` و`integration_call`. توجد وصلة مباشرة من ملفات المهمة. يمكن إلغاء التفعيل بالطريقة نفسها.
- الصلاحيات محفوظة لكل مهمة خارج مجلد ملفاتها؛ لا تُورث إلى المهام الأخرى. نمط استكشف لا يستطيع استدعاء البوابة، ولا يمكن تغيير الصلاحيات أثناء تشغيل المهمة أو انتظارها في الطابور.
- أدوات التكامل تستخدم نطاق الخدمة الخارجية المهيأ؛ لا توصف ملفاتها وحساباتها بأنها معزولة داخل المهمة. تفعيل الأداة لا يعني تفويض كل إجراء خارجي، ويظل الطلب يحدد الإجراء المطلوب.
- البحث `web_search` متاح في نمط ابحث ويعيد عناوين وروابط من DuckDuckGo. حدود الاستجابة والمهلة والإلغاء وسياسة الشبكة مطبقة؛ تحديات المزود وأخطاؤه تظهر كفشل ولا تتحول إلى نتائج مختلقة.
- اختبار الواجهة العام يستخدم صفحات الجوال والأمن والأسراب الفعلية بدل توقع أزرار الموك القديم.
- استديو الجوال الفعلي كان قد أضيف إلى المشروع بعد المراجعة الأولى؛ جرى الحفاظ عليه والتحقق من تشغيل الأدوات والتنقل والبيانات والتصدير والعزل.

## الأدلة

- `npm run verify:loam` نجح، بما يشمل TypeScript والترميز والتقييم والتنفيذ والاستعادة والعزل والوكلاء والواجهة والاختبار الشامل والتكاملات والبحث.
- `npx tsx src/scripts/check-mobile-http.ts` نجح.
- اختبار بحث حي أعاد رابط وثائق TypeScript وموقعه الرسمي من الأداة الجديدة.
- اختبار التكاملات يستخدم خدمة اصطناعية؛ يثبت انتقال الإذن من الواجهة إلى تنفيذ الأداة ومنع العبور بين المهام وإلغاء الإذن، ولا يثبت جودة جميع الأدوات الخارجية.

## التثبيت والتحقق النهائي

ثُبّت الإصدار 0.5.5 وشُغّل على ملف المستخدم السابق. بقيت المهام الـ12 ومعرّف الملف كما هي. أعادت مسارات الجوال والأمن والأسراب والتصميم والتكاملات الحالة 200، وعرض الكتالوج 345 أداة تكامل. نجح اختبار Electron المجمّع بملف اختبار مستقل، بما يشمل اتصال خوادم MCP الخمسة والطرفية والأوفيس وصفحة التكاملات ومسارات الاستديوهات. سجل التثبيت: `output/verification/service-fixes-install.json`.

## الاستخدام

افتح الخدمات ثم التكاملات، واختر مهمة أو أنشئ مهمة تكامل جديدة. ابحث عن الأداة المطلوبة وفعّلها واحفظ، ثم افتح المحادثة واطلب من المساعد استخدامها. تعرض المدخلات تفاصيل كل أداة. التكاملات غير المتاحة تحتاج اعتمادها أو تثبيت خدمتها؛ ظهور الأداة في القائمة يعني تسجيلها وليس نجاح كل عملياتها.
