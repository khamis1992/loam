# Loam — مراجعة التكامل وإعادة التصميم

## ما تغيّر

هوية موحدة باسم Loam مع استعادة ألوان وتخطيط التصميم السابق بناءً على توجيه المستخدم: خلفيات داكنة وتدرجات سماوية وبنفسجية، ومظهر فاتح بارد، وشريط أيقونات جانبي ولوحة مهام ومحرّر طلب مركزي. أزيل التصميم النباتي. التحسينات تشمل وضوح التنقل وطيّ اللوحة وتمرير الطلب إلى صفحة النمط قبل التنفيذ. صفحات المساعدين والمهارات والذاكرة والمعرفة والتقييم والشاشة والطرفية تحمل الهوية نفسها. عناوين Electron والقائمة وشريط النظام والمثبت تغيرت إلى Loam.

صفحات الأنماط السبعة مستقلة بروابطها وحقولها وإرشاداتها وأدواتها؛ الأسئلة تعرض القراءة فقط، البيانات تركز على الملف والمقاييس، التصميم يركز على الموجز والأسلوب والمعاينة، والبناء يتيح الاختبار والمعاينة. الصلاحيات مفروضة داخل ToolRegistry وتمنع النمط غير المعروف واستدعاء أدوات خارج القائمة، بما فيها التفويض وMCP غير المصرح به. ظلت البروتوكولات وأسماء المزودين الحقيقية كما هي، ولم تُسمَّ خدمات خارجية باسم Loam.

مساحة المهمة تُنشأ قبل رفع المرفق. معرف المهمة مطلوب لمسارات الملفات والوسائط والمعاينة والطرفية والرموز والفحوص. تُمنع المسارات الخارجة والروابط الرمزية بين المجلدات. مساحة مهمة قديمة لا تتغير عند تغيير مجلد العمل العام. لا تُحقن ذكريات المهام السابقة أو أدوات خلفية مشتركة تلقائيًا. بقيت إدارة الذاكرة العامة قسمًا مستقلًا وصريحًا.

المهام القديمة لا تفقد بياناتها؛ لكنها لا تستأنف نقاط حفظ كتبت إلى المجلد المشترك القديم. المتابعة الجديدة تحصل على مجلد مستقل فارغ. الواجهات القديمة التي تعدّل checkout مشتركًا أو تشغّل تطبيقًا خارجيًا أُوقفت برمز410. نمط البناء ليس sandbox لنظام التشغيل، إذ يعمل shell بصلاحيات المستخدم.

## حدود التحقق والتشغيل — سجل المراجعة الأولية

تحديث 2026-10-18: أُصلح جسر MCP واختُبرت الخدمات الفعلية وبُني مثبت Loam وثُبّت. راجع `loam-release-verification.md` و`loam-services-final.md` للنتائج الأحدث؛ النقاط أدناه توثق الحالة السابقة لهذه الأعمال.

- مزودات السحابة والخدمات الاختيارية تحتاج إعدادها واعتماداتها واختبارها منفردة. لم يثبت بروتوكول اتصال جسر الوكلاء على3001 في فحصه الحالي.
- مشاركة شاشة الجهاز صريحة وعلى مستوى الجهاز؛ لم نلتقط شاشة المستخدم ضمن هذه المراجعة.
- إعدادات مثبت Loam جاهزة، لكن لم يُبنَ أو يُثبت إصدار Windows جديد ولم يُنشر تحديث. التغذية القديمة ما زالت تشير إلى المثبت السابق.
- TestSprite غير مثبت. استُخدمت اختبارات Node/TypeScript وPlaywright المحلية؛ يمكن إعداد TestSprite عبر `testsprite setup` بعد تثبيت CLI.
- graphify خرج برمز1 دون تقرير عند البناء/التحديث، لذلك جرت مراجعة الشيفرة مباشرة.
- التطبيق المثبت الجاري قد يستمر بالشيفرة القديمة حتى إعادة تشغيله من المصدر أو تثبيت إصدار Loam؛ لا نُوقف مهام المستخدم القائمة لإجراء الاختبار.

الحكم: الواجهة ومسارات التكامل والعزل المذكورة اجتازت الفحوص. الخدمات الاختيارية والمثبت غير مختبرة بالكامل، لذلك لا ادعاء بجاهزية جميع الخدمات الخارجية للإنتاج.
