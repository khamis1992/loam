## Design decisions
- Config key `wiki.enabled`, default **false** (D-C1). Every entry point checks it.
- `sanitize.ts` is the only write boundary: it runs `assertNoSecret` on every string headed for disk or export.
- Handoff state transitions use a compare-and-set `UPDATE ... WHERE state='open'` so two sessions cannot both claim one handoff.
- The session-start notice is metadata only (title, id, age); the body is never injected.
- Wiki pages that are recalled into a prompt go through `markUntrusted`.
