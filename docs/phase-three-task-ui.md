# المرحلة الثالثة: شاشة المهمة

تفتح المهمة على ملخص الطلب الحالي: النتيجة، الخطة ومعايير الإنجاز، التحقق، والملفات التي أكدت أدوات الملفات حفظها أو تعديلها. يبقى سجل المحادثة والتنفيذ متاحًا في تبويب مستقل. الملفات المعروضة ليست جردًا كاملًا لمخرجات أوامر الطرفية أو الأدوات المركبة؛ يمكن فحص مساحة العمل للوصول إلى بقية الملفات.

حالة اكتمال المهمة منفصلة عن نتيجة التحقق. تنفيذ خطوة لا يعني اجتياز مراجعتها، وغياب تحقق نهائي يظهر صراحة. لا تنتقل إجابة الطلب السابق أو أدلته إلى ملخص توجيه جديد.

زر الإيقاف أو إلغاء الانتظار يظهر للمهام النشطة، وإضافة التوجيه تنقل التركيز إلى مربع الكتابة. المهام القابلة للاستئناف تعرض نقطة الحفظ، وتتطلب تأكيدًا إذا كانت إعادة الخطوة قد تكرر أثرًا سابقًا. تبقى مساحة العمل قابلة للفتح والإغلاق، مع عرض مستقل على الشاشات الضيقة.

## التحقق

- `npm run check:task-ui`: اختبار Playwright باستخدام Edge وواجهة الخادم الوهمية؛ لا يشغّل نموذجًا ولا يغير بيانات المستخدم. يغطي الحالات الست، فصل الطلبات، الملفات الناجحة، استمرار معرّف المحادثة، تأكيد الاستئناف وإلغاءه، لوحة المفاتيح، RTL/LTR، عروض 320 و768 و1440 بكسل، والتكبير 200%.
- `npm run verify`: فحص الأنواع والترميز، التقييم، المنسّق، والتخزين والاستئناف.
- اختبار الواجهة يتطلب تثبيت Microsoft Edge. لقطة الفحص تُحفظ في مجلد النظام المؤقت باسم `manus-task-ui-check.png`.

لم يتوفر TestSprite CLI في بيئة التنفيذ، وتعذر تحديث graphify لأن الأمر خرج دون تقرير. الاختبارات أعلاه محلية، وليست تحققًا عبر TestSprite أو تشغيلًا متكاملًا بنموذج فعلي.
