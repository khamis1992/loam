# روابط شاشات استوديو الجوال

أضيف زر «رابط الشاشة» فوق الهاتف. ينشئ رابطًا محليًا يفتح المشروع والشاشة المحددين داخل واجهة Loam، مع نسخ الرابط أو فتحه في تبويب جديد. تُحفظ التعديلات أولًا عند الحاجة، كما يوضح تلميح الزر؛ لا ينشر هذا الرابط التطبيق على الإنترنت.

صيغة الرابط: `/?mobileTask=<taskId>&mobileScreen=<screenId>#/studios/mobile`.

مسار الصفحة يعرض الأسلاف مرة واحدة دون تكرار اسم المجموعة. روابط الأسلاف تدعم النقر داخل الاستوديو أو الفتح في تبويب آخر. يتزامن العنوان مع الشاشة عند التنقل في الهاتف أو المستكشف، وتستعيد إعادة التحميل الشاشة نفسها. الشاشة المحذوفة تعود إلى أول قسم مع رسالة واضحة.

التحقق: `check-mobile-links.ts` نجح في الفتح المباشر والنسخ والتبويب الجديد ومسار الأسلاف ومزامنة المعاينة وإعادة التحميل واستعادة المشروع السابق ومعالجة الشاشة المفقودة وعرض 320px. اختبارات `check-mobile-preview-layout.ts` و`npm run check:mobile` نجحت أيضًا، بما فيها مشروع الأربعين صفحة والحفظ والرجوع والتصدير.

الأدلة: `release/mobile-live/screen-links/verification.json` و`live-final.jpg`. لم تتغير بيانات رفيق الإنجاز أو بنية صفحاته.
