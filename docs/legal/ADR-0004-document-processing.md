# ADR-0004: معالجة المستندات وOCR

## القرار

يكون الاستخراج موضعياً: يحفظ الملف الأصلي وبصمته، ويعيد صفحات وفقرات وجداول ومواضع وتحذيرات، لا نصاً مجرداً. يدعم OCR المحلي العربية والإنجليزية عبر `OcrProvider` القابل للحقن الموجود في معمارية Knowledge، دون أي خدمة سحابية.

## اختيار التنفيذ

يحدد تنفيذ OCR بعد benchmark على مستندات عربية وإنجليزية ممسوحة. المعيار: جودة النص، دعم المثبت دون اتصال، الذاكرة والزمن، وإمكانية حزم اللغات. الواجهة والاختبارات لا ترتبطان بمحرك بعينه. لا يعد OCR مكتملاً إذا لم يعمل داخل المثبت النهائي.

## السلامة

- تحسب جودة/ثقة كل صفحة وتعرض الصفحات منخفضة الجودة للمراجعة.
- لا تستنتج المنظومة تزويراً أو صحة توقيع من OCR.
- تقسم الملفات الكبيرة مع الاحتفاظ بالمواضع والسياق، وتكون الحدود معلنة لا فشلاً صامتاً.
- لا تدخل صفحة أو صورة في نموذج أو provider خارجي.
