- `npm run typecheck`: ناجح.
- `npm run check:mobile`: ناجح، بما فيه تطبيق 40 صفحة وتحقق API والعزل والتنقل والحفظ والتصدير.
- `npm run check:mobile:android`: ناجح؛ هوية مستقرة، أصول حرفية، XML آمن، تعارض إصدار، حالة انقطاع، منع APK غير مكتمل، تصدير مصدر وبصمة، وأدوات التوافق التي تصدّر المشروع الحقيقي.
- `npx tsx src/scripts/check-mobile-android.ts --cancel`: ناجح بعد بدء Gradle، مع منع بناء متزامن ورفض تنزيل ناتج العملية الملغاة.
- واجهة المتصفح: بدء بناء فعلي، إغلاق نافذة البناء وإعادة فتحها، استرجاع النتيجة، تنزيل APK.
