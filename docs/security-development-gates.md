## Required evidence before claiming comprehensive capability

| Area | Current evidence | Remaining delivery gate |
| --- | --- | --- |
| Browser and SPA | Nutrio login form assertions completed; overall coverage partial | Complete dependency loading; explicit readiness and failure reasons per route; production-build and development-mode regression fixtures |
| API and auth origins | Login, scoped POST and redirects work in same-origin fixtures | Explicit frontend/API origin roles, exact method/path grants, origin-bound credentials, CORS/preflight integration, negative credential-leak fixtures; no implicit cloud origin approval |
| Sessions and authorization | Isolated account contexts and identity witnesses implemented | Nutrio test accounts and synthetic owned records; horizontal and vertical permission matrix; session-expiry and MFA-aware workflows |
| Discovery | Scoped HTML links and static OpenAPI GET paths | Parameterized API operations, user-supplied test data, SPA navigation graph and coverage denominators; explain skipped operations |
| Detection | HTTP/configuration checks and selected browser validations | Versioned ASVS requirement inventory with supported, manual and unsupported states; independently labeled vulnerable/fixed applications; false-positive and false-negative measurements |
| Source and dependencies | Basic source heuristics, npm inventory and advisory matching | Framework-aware analysis, reproducible tool adapters and normalized evidence; avoid treating heuristics as confirmed exploitation |
| Remediation | Findings, triage and coverage-aware retests | Source-linked proposed patches in isolated worktrees, regression tests and reviewable diffs; exact original reproducer plus allowed-control test after repair |
| Operational quality | Scoped requests, quotas and cancellation | Resource budgets visible/configurable within bounded limits, robust cancellation/recovery, secret isolation, task tenancy, retained evidence integrity, UI-to-runtime verification |
| Independent evaluation | Internal fixtures only | Reproducible benchmark suite, documented versions and environments, third-party review, performance and coverage results over diverse applications |
