# المشاريع الكبيرة والتصدير الخلفي — 2026-10-18

## التغيير

أصول المونتاج محفوظة كملفات مستقلة داخل `assets/timeline` في مساحة المهمة. رفعها متدفق إلى القرص، ومشاهدة الوسائط تدعم HTTP Range. أزيل حد 45 MB من مشروع المونتاج وحد 30 MB من استيراد مصادره، ولا تُنسخ ملفات الوسائط إلى سجلات التراجع أو الاستعادة. وصف المشروع وحده محدود بـ2 MB، منفصلًا عن حجم الأصول. قيود عدد المقاطع والمسارات ومدة المشروع السابقة باقية.

JSON الجديد وصف مرتبط بأصول المهمة. يمكن إعادة فتحه أو استيراده إلى مهمة أخرى داخل التطبيق (تُنسخ الأصول إلى المهمة الجديدة). ملفات JSON القديمة ذات الأصول المضمنة تتحول عند الاستيراد إلى التخزين المستقل. لن يكفي نقل وصف JSON وحده إلى جهاز لا توجد فيه الأصول.

تصدير MP4 وWebM ينتقل إلى طابور دائم في الخادم. كل عملية تحفظ نسخة من المشروع، ويرسمها Edge غير المرئي بنفس محرك المعاينة، ثم يرمّز FFmpeg إطارات كل جزء بتوقيت ثابت، ويجمع الصوت غير المضغوط قبل ترميزه مرة واحدة. جزء مكتمل كل خمس ثوانٍ من الفيديو يشكل نقطة استكمال محفوظة. لا ترتبط العملية بعمر نافذة المحرر أو صفحة الواجهة. عند إغلاق التطبيق بالكامل يتوقف العمل؛ عند تشغيله تستأنف العمليات المنتظرة أو المنقطعة تلقائيًا. الجزء الجاري غير المكتمل قد يعاد، أما المكتمل فلا يعاد. إعادة محاولة العملية الملغاة أو الفاشلة تحتفظ بالأجزاء المكتملة.

تُكتب النتائج إلى القرص مباشرة دون حد رفع 50 MB القديم. المساحة المتاحة وقدرة الجهاز والترميز تظل حدودًا فعلية؛ لم يُدّع دعم حجم غير محدود ماديًا أو اختبار مشاريع بحجم تيرابايت. التصدير إطارًا بإطار ثم مرحلة دمج محلية؛ لا يعتمد على سرعة تشغيل المعاينة. تحفظ ملفات الصوت المؤقتة ونقاط الاستكمال على القرص وتحتاج مساحة إضافية. أسماء ملفات كل محاولة منفصلة حتى لا يتعارض الترميز المتبقي من عملية مقطوعة مع المحاولة التالية.

## التحقق

- `npm run check:creative-large`: رفع ملف WAV صالح بحجم **57,600,044 بايت** من منتقي ملفات الواجهة، إضافة صورة، تحرير المدة، حفظ وصف صغير دون base64، فتحه من قائمة المشاريع وإعادة استيراد JSON.
- تحقق HTTP Range بإجابة 206 وبداية WAV الصحيحة؛ لا يحتاج المشغل تحميل المصدر كاملًا حتى يتمكن من الانتقال داخله.
- إرسال التصدير من الواجهة، إغلاق المحرر والمتصفح، التحقق من استمرار العمل، ثم قتل خادم الاختبار بعد اكتمال الجزء الأول وإعادة تشغيله بنفس بيانات المشروع.
- فتح الواجهة مجددًا ومشاهدة العملية نفسها حتى الاكتمال، والتحقق من أن وقت تعديل الجزء الأول لم يتغير؛ هذه شهادة إعادة استخدام نقطة الاستكمال وليست إعادة تصدير صامتة من البداية.
- تنزيل MP4 الناتج من الواجهة وفك الفيديو والصوت. فيديو مدته نحو 12 ثانية، إطار أخضر صحيح بعد نقطة الاستكمال، وRMS للصوت نحو 0.086.
- `npm run check:creative-large -- --installed` اجتاز الدورة نفسها باستخدام ملفات النسخة المثبتة وبيانات معزولة.
- `npm run check:creative-large -- --desktop` اجتاز الدورة داخل تطبيق Electron المثبت **Loam 0.5.20** نفسه بملف مستخدم مؤقت. أُغلق التطبيق وأُعيد فتحه، وأعيد استخدام الجزء المكتمل، ثم نُفّذ تنزيل النتيجة من رابط الواجهة عبر حدث الحفظ الأصلي `will-download` إلى مسار اختبار. تقرير الدليل يسجل `desktop: true` و`installed: true`.
- `npm run check:creative-http -- --bundle` اجتاز اختبارات المشهد وGLB/JSON والوسائط والمؤثرات والمونتاج والانتقالات والقوالب وSRT والكتم والتراجع والحفظ وطابور التصدير بعد تحديث الاختبارات إلى API الخلفية.
- `npm run typecheck` و`npm run check:encoding` نجحا.

الأدلة: `output/verification/creative-large-report.json`، و`creative-large-resumed.mp4`، و`creative-large-resumed.png`. الاختبار في `src/scripts/check-creative-large.mjs`، ومحرك الخلفية في `src/creative/timeline.ts`.
