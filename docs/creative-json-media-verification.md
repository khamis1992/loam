# JSON والصور والفيديو — تحقق 18 أكتوبر 2026

أضيف الاستيراد المحمول للمشهد ونافذة الوسائط إلى استديو «صمّم»، وطُبّقت سبعة ملفات واجهة على Loam المثبت (0.5.12) دون إعادة تشغيله؛ حافظ التثبيت على ملف المستخدم ومهامه الـ28 الموجودة وقت الفحص.

## نتائج التحقق

- `npm run check:creative-http`: نجح على خادم المصدر ببيانات مؤقتة منفصلة.
- `npm run check:creative-http -- --installed`: نجح على حزمة الخادم وملفات الواجهة المثبتة، بخادم منفصل وبيانات مؤقتة؛ لم يُستخدم ملف المستخدم الحي للاختبارات التي تكتب بيانات.
- `npm run check:creative-ui`: نجح للعرض ثلاثي الأبعاد والأدوات المباشرة والتعارض والتجاوب.
- `npm run typecheck` و`npm run check:encoding`: نجحا.

تضمن اختبار الواجهة الفعلي تنزيل JSON لمشهد يحوي سبعة عناصر ونموذج GLB مضمّن، وفتحه في مهمة جديدة، والتحقق من إعادة ربط الأصول وعدم استخدام رقم إصدار الملف، وتعديل عنصر وحفظه وتصديره مرة أخرى. اختُبرت ملفات JSON القديمة ذات المجسمات الأساسية، ورفض الملف غير الصالح دون فقد المشهد، وإلغاء الاستبدال وتأكيده والتراجع عنه.

اختبارات الوسائط استخدمت صورة مولّدة للاختبار وفيديو مولّد بصوت: اقتصاص ودوران وأبيض وأسود ونص وتصدير PNG مع فحص البكسلات والأبعاد؛ حفظ JSON الوسائط في المهمة، قراءة الملف الفعلي، وإعادة فتحه من قائمة مشاريع المهمة؛ قص فيديو وتطبيق السطوع وتصدير WebM وإعادة استيراده مع التحقق من مدة ثانية واحدة، وتصدير مكتوم الصوت، وإلغاء التصدير دون تنزيل ملف جزئي. نجح فحص عرض النافذة على عرض 390 بكسل ولم تُسجل أخطاء JavaScript.

توجد لقطة النافذة في `output/verification/creative-media-editor.png` وتفاصيل الاستخدام والحدود في `docs/creative-studio.md`.

النطاق: تحرير صورة أو مقطع فيديو واحد، وليس مونتاجًا متعدد المسارات. الفيديو يصدر WebM بالوقت الفعلي؛ الصور PNG. لا يشمل MP4 كصيغة تصدير أو توليد الوسائط بالذكاء الاصطناعي أو تسجيل فيديو للمشهد ثلاثي الأبعاد. جودة الملفات الخارجية تعتمد على ترميزات المتصفح؛ لم يُختبر كل ترميز أو كل ملف خارجي.
