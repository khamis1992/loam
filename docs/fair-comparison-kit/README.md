# عدة المقارنة العادلة — Loam مقابل مساعد مرجعي

الهدف (قسم 24): مقارنة عادلة قابلة لإعادة التجربة بين مساعدي Loam وأي مساعد مرجعي
(ChatGPT Agent، dots، Grok Bot...) على المهام نفسها، بالصلاحيات والزمن نفسيهما.

## طريقة التشغيل
1. **جهّز Loam**: شغّل التطبيق ثم `npm run check:companions-live-bench`
   (أو المجموعة الكاملة عبر توسيع الحالات) — النتائج تُصدَّر إلى
   `docs/evidence/companions-bench-live.json` (صحة + تدخلات + زمن).
2. **شغّل المساعد المرجعي**: نفّذ المهام الست من `tasks.json` حرفيًا عنده
   بنفس العقد (نفس الأوامر، نفس الصلاحيات، 10 دقائق/مهمة)، وسجّل نتائجه في
   نسخة من `reference-results-template.csv`.
3. **وازن**: `npx tsx docs/fair-comparison-kit/score.ts --loam docs/evidence/companions-bench-live.json --reference <csv>`
   — يخرج تقرير مقارنة (صحة، إكمال، تدخلات، زمن) ويكتب
   `docs/evidence/fair-comparison.json`.

## قواعد العدل
- نفس النصوص حرفيًا (لا إعادة صياغة)، وصلاحيات مكافئة لا أوسع لأي طرف.
- تدخل المستخدم يُحسب فقط حين يطلبه النظام فعليًا (موافقة/توضيح).
- الصحة ضد الآثار الجانبية الملموسة (ملف/مهمة/ذاكرة) — لا ضد نص الرد.
- تُسجَّل حالات الفشل كما هي: التقرير يظهر أين يفشل كل طرف.

## حدود
مجموعة أولى من 6 مهام (3 عربية + 3 إنجليزية) عبر الخدمات الأساسية؛ التوسيع
لمهام طويلة ومتقاطعة بند تطوير مع القياس الحي نفسه.
