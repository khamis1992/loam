# موك مساحات Loam

افتح `index.html` في المتصفح. توجد خمس صفحات عبر شريط التنقل:

- `#mobile`: الجوال — الشاشات ومحاكي iOS / Android وتدفق المستخدم وفحص المتجر.
- `#office`: الأوفيس — معاينات Word / Excel / PowerPoint وغرفة القيادة والمصادر.
- `#security`: الأمن — نطاق الفحص والنتائج وخطة المعالجة والسجل.
- `#creative`: الإنتاج الإبداعي — تصور المجسّم والخامات والشبكة والخط الزمني والأصول والإخراج.
- `#swarm`: الأسراب — شبكة الفريق والمهام ومحاكاة الجمهور والمخرجات.

هذه ملفات تصميم مستقلة. كل البيانات تجريبية، والمجسّم مرسوم بـ CSS؛ لا تنفّذ الصفحات خدمات أو عمليات تصدير أو فحص فعلية. مساحة تطوير التطبيقات الموجودة لم تُعدّل.

التحقق: `node docs/mockups/workspaces/verify.mjs` من جذر المشروع؛ يستخدم Playwright وEdge لالتقاط الصور وفحص الصفحات والتفاعلات والتجاوب.

المعاينة المحلية الاختيارية: `node docs/mockups/workspaces/serve.mjs`، ثم افتح العنوان المكتوب في `preview-url.txt`. يستخدم منفذًا متاحًا على 127.0.0.1 فقط.
