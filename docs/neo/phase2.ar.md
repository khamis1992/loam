# دليل قدرات المرحلة الثانية (عربي)

يغطي هذا الدليل القدرات التي هبطت في تحديث 0.5.32 («إتمام الجسور + وصول إلى العالم»). كل ميزة موصوفة بسلوكها الفعلي في هذا الإصدار، ومتى احتاجت مفتاحًا منك (BYOK) أو إعدادًا قال ذلك صراحة.

## تحدث مع ملفاتك (RAG في المحادثة)

أدوات حديقة المعرفة (kb_*) أصبحت متاحة في وضعي **اسأل** و**بناء** افتراضيًا — لا حاجة لتشغيل وضع خاص.

- **زر «تحدث مع ملفاتك»** بجوار مربع الكتابة: يفلتر ملفات المهمة الحالية في حديقة المعرفة ثم يجيب من ملفاتك فقط.
- **أداة `task_files_ingest`**: يستهلكها الوكيل تلقائيًا، ويمكنك طلبها صراحة («فلتر ملفات هذه المهمة في حديقة المعرفة»).
- للإطفاء: الإعدادات العامة ← عطّل `knowledgeRag`.
- أدوات `rag_index`/`rag_query` القديمة أصبحت توجه إلى حديقة المعرفة نفسها (الجسر الخارجي المكسور أُغلق).

## الترجمات التلقائية (SRT/VTT)

أداة `creative_subtitles {mediaPath}`: تفريغ صوتي عبر خادم STT المحلي ثم كتابة ملفي `.srt` و`.vtt` بجوار الفيديو. تعمل في وضع «صمّم» ومن نقطة البداية «ترجمات تلقائية». يتطلب تشغيل خادم STT: `npm run stt` (whisper محلي، لا سحابة).

## محرك تشغيل التطبيقات (App Builder)

- **وضع Build**: أرسل وصف التطبيق ← الوكيل يسأل أسئلة توضيحية (بطاقة أسئلة) ← مسودة خطة توافق عليها أو تعدلها ← تنفيذ ← تحقق (check/lint/typecheck/build) ← لقطة إصدار. كل تشغيل موثق في صفوف `app_runs` ومقفل لكل مشروع.
- **وضع Goal**: خطة متعددة المهام بموافقة، ثم تنفيذ تسلسلي لكل مهمة.
- **السباق (Race)**: فروع متوازية بنماذج سحابية متمايزة ودرجات إبداع مختلفة، ثم اختيار الأفضل وترقيته. المسارات كلها حية الآن (لا المزيد من رسائل 501).
- قاعدة صارمة: خطوات البناء والتخطيط **سحابية حصرًا** — لا نموذج محلي لهذه الخطوات (يفشل التشغيل برسالة عربية واضحة إن لم يوجد نموذج سحابي).

## النشر والخدمات الخلفية

- **أهداف نشر حقيقية**: `deploy_app` بـ `target: vercel|netlify` ينشر فعليًا عند توفر `VERCEL_TOKEN`/`NETLIFY_AUTH_TOKEN` في البيئة (ثابت فقط — يرفض أي تطبيق يستدعي APIs بنفس الأصل).
- **Stripe لمفاتيحك**: ضع مفتاحك في الخزنة (مدى التطبيقات) أو `STRIPE_KEY` في البيئة — يصل إلى خادم التطبيق المولد تلقائيًا، ولا يُسجل أبدًا.
- **مزامنة SQLite**: نقطة نهاية `__loam/sync/pull|push` (سقف 25MB، كتابة ذرية).
- **بناء المتاجر**: `npm run eas:build -- --platform android` (يتطلب eas CLI مسجل الدخول بحسابك).

## الصور والصوت

- **توليد صور AI**: أضف `cloudModel.images.model` في config.json (أو `LOAM_IMAGE_MODEL`+`LOAM_IMAGE_BASE_URL`+`LOAM_IMAGE_API_KEY`) — مزود متوافق openai-compatible بمفتاحك.
- **الصوت في المحادثة**: زر المايك (تحدث) بجوار مربع الكتابة — تعرف صوتي عربي مع عرض فوري، وزر السماعة (تشغيل/إيقاف الصوت الآلي) ينطق الردود. الكلام أثناء النطق يوقفه (barge-in).

## لُوام Remote (من هاتفك)

افتح `http://<عنوان-الجهاز>:<المنفذ>/remote` من الهاتف على نفس الشبكة (أو عبر Tailscale)، الصق التوكن مرة واحدة، ثم: قائمة مهام حية، عرض المخرجات، إيقاف/استئناف. أضفها للشاشة الرئيسية كتطبيق (PWA).

## دورة تطوير GitHub

وضع **devflow**: issue ← فرع ← سرب نتريو ← PR ← مراجعة ← CI، وربع أمنية (فحص remediation ← رقع ← PR). المهارة: `skills/dev-flow`.

## السوق

صفحة المهارات أصبح فيها تبويب ثالث «السوق»: شبكة موحدة لتثبيت/تفعيل المهارات والجسور والموصلات من مكان واحد.

## قناة التحديث

التطبيق المثبت يفحص GitHub Releases تلقائيًا. للنشر: `npm run dist && npm run publish:release` (يتطلب gh مسجل الدخول). التوثيق الكامل في ملف docs/update-channel.md داخل المستودع.
