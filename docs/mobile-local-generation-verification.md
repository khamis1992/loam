# اختبار بناء تطبيق متعدد الصفحات بالنموذج المحلي

التاريخ: 2026-10-18. الخادم: `127.0.0.1:3941`. النموذج: Ollama `qwen2.5:14b` محلي، Q4_K_M، دون نموذج سحابي أو مشروع تجريبي جاهز.

## النتيجة

أنشأ النموذج «رفيق الإنجاز» من مشروع فارغ ووصف عربي عبر زر البناء في الاستوديو. المهمة `task_mvdb5dyx6cb1a5e47e9a`. الناتج 20 شاشة: أربعة أقسام رئيسية و16 صفحة فرعية، منها أربع صفحات ذات أب فرعي. عدد روابط الانتقال الفعلية 21، وكل الصفحات قابلة للوصول. النموذج اختار المحتوى والمعرفات والآباء والروابط؛ لم تُكتب الشاشات أو تُصحح يدويًا.

فشلت الجولة الأولى في المحاولات الثلاث: صفحة بلا أب ثم تجاوز عدد الأقسام الرئيسية. عُدّل مخطط التوليد ليفصل sections عن pages ويلزم الأخيرة بـparentId. أُضيف فحص أزرار الوصول من الآباء إلى الأبناء. أُعيد الطلب نفسه من المشروع الفارغ، ونجح في المحاولة الثالثة بعد إصلاح النموذج رابط تقييم الجلسة ثم رابط تفاصيل المهمة. بعد ذلك جُمعت الروابط الناقصة في رسالة خطأ واحدة لتحسين الإصلاح اللاحق؛ هذا التجميع اختُبر آليًا بروابط متعددة، ولم يُنسب إليه تسريع التجربة الحية السابقة.

## التحقق المنفذ

`npx tsx src/scripts/check-mobile-generated.ts task_mvdb5dyx6cb1a5e47e9a` يقرأ المشروع الحي ولا يزرع شاشات بديلة. نجح في:

- فحص الأقسام الأربعة والصفحات العشرين وعلاقات الآباء والأبناء والروابط الـ21.
- 83 انتقالًا و62 رجوعًا، تشمل كل رابط مولّد، مستويات متداخلة، رابطًا عابرًا بين قسمين، والرجوع إلى الأم عند الفتح المباشر من المستكشف.
- إدخال وحفظ واستعادة 16 حقلًا نصيًا و16 مفتاح إكمال بعد إعادة تحميل الصفحة، وتجربة 16 زر حفظ دون تغيير الشاشة.
- البحث ومسار الصفحة وخريطة التدفق دون صفحات يتعذر الوصول إليها.
- التراجع عن البناء إلى المشروع الفارغ وإعادته، ثم الاحتفاظ بالناتج بعد إعادة تشغيل الخادم؛ المراجعة النهائية 4.
- عدم تجاوز عرض الواجهة والمعاينة عند 1110 و768 و320 بكسل.
- تصدير ZIP وتجربة الوصول إلى كل صفحة والرجوع في HTML المصدّر، وفحص تركيب JSX لمصدر Expo.
- عدم ظهور أخطاء JavaScript في المتصفح.

جُرّب يدويًا أيضًا: مشاريعي ← مهمة اليوم ← تفاصيل المهمة ← ابدأ جلسة تركيز ← جلسة دراسة ← رجوع. عاد إلى تفاصيل المهمة مع النص المدخل محفوظًا.

نجحت فحوص TypeScript والترميز، واختبارات البناء والإلغاء والتعارض والإصلاح، واختبار التكامل على حزمة الخادم. لم يُنفذ بناء APK/IPA أو اختبار جهاز أصلي.

## ملاحظات الجودة

النموذج كتب «مراجعاتي» بدل «مراجعتي»، ولم يضف النص الترحيبي المطلوب إلى الأقسام الرئيسية، وكرر بعض تسميات الحقول في صفحات مختلفة مع معرفات مستقلة. لذلك النجاح يثبت عمل التنقل والنماذج والحفظ المحلي ضمن قدرات الاستوديو الحالية، ولا يثبت التزامًا حرفيًا بكل تفاصيل الوصف أو جودة تحريرية نهائية أو خدمات خلفية.
