> كل خطوة أدناه موثقة بسلوكها الفعلي في الكود (ملف:سطر)

## الخطوة 1 — التثبيت (نقرة واحدة)

شغّل `Loam-Setup-0.5.35.exe` الموقّع (SHA-512 مثبت في latest.yml على قناة GitHub Releases) واضغط «تثبيت». المثبّت NSIS يثبت في `%LOCALAPPDATA%\Programs\loam\` ويُنشئ اختصارًا على سطح المكتب. لا حاجة لأي إعداد قبل التشغيل.

**الدليل:** electron-builder NSIS config + التوقيع بـ signtool في سجل البناء (`docs/dist-0535.log`).

## الخطوة 2 — الإقلاع: تسجيل دخول محلي تلقائي (بلا شاشة دخول)

افتح Loam من الاختصار. العملية الرئيسية تولّد توكن تثبيت 256-بت وتخزنه في `%APPDATA%\Loam\.loam-local-auth-token` وتحقن كل طلب تلقائيًا (main.cjs:696-710, 866-869)، وتصدر جلسة محلية تلقائيًا بلا أي شاشة تسجيل (main.cjs:746-779). النافذة تفتح على Agent Studio مباشرة.

**ملاحظة توقيت:** الخادم الداخلي (623 أداة + 5 خوادم MCP) يجهز خلال ثوانٍ — إن ظهرت الواجهة قبل الجاهزية انتظر 3–5 ثوانٍ وستتصل تلقائيًا (الإصلاح الدائم لرسائل fetch المبكرة مجدول ضمن موجات الواجهة القادمة).

## الخطوة 3 — اكتب طلبك في الصندوق الواحد واضغط «تلقائي»

اكتب طلبك بلغتك (عربي/إنجليزي). مع فعالية رقاقة **«تلقائي»** (الافتراضي)، يستدعي المُركّب موجّه النية (POST /api/intent/route — طبقة كلمات فورية + نداء سحابي واحد بدرجة حرارة صفر) فيختار النمط من الـ12، ويعرض سطر شرح عربي قابل للإخفاء: «اخترنا وضع …». التحكمات المتقدمة (النموذج/الطبقة/الجهد/مقارنة النماذج) مطوية خلف ⚙️ وتُحفظ تفضيلاتك مرة واحدة.

**الدليل:** src/server/intentRouter.ts + intentKeywords.ts/intentModel.ts · Composer.tsx (Auto chip + ⚙️) · دقة القياس: **20/20 = 100%** على الطلبات المتنوعة (scripts/measure-intent-accuracy.ts).

## الخطوة 4 — البوابات الحرجة فقط تطلب قرارك

أثناء التنفيذ، تظهر بطاقات الموافقة عند النقاط ذات الأثر (وصول للمجلد، تنفيذ أوامر، خطة المهام) — اضغط موافقة مرة واحدة لكل نوع. خيار «موافقة عني» يجعل التكرارات تلقائية، وبوابات الأمن تبقى دائمًا بقرارك (سياسة الفريق الأحمر الثابتة).

**الدليل:** components/chat/EventList.tsx:143-177 (بطاقات الموافقة) · Composer.tsx (Approve-for-me) · src/modes/catalog.ts (بوابة الأمن تحفظ القرار للمستخدم).

## الخطوة 5 — المخرجات في مكانها

عند الاكتمال: الملفات في لوحة ملفات المهمة (تُفتح بمحررها تلقائيًا عبر بوابة المحررات)، الإصدارات في تبويب الإصدارات مع الاسترجاع، والمتابعة من أي جهاز عبر `/remote`. ميزة الذاكرة تعمل تلقائيًا (نموذج التضمين مثبت مع 0.5.33+).

**الدليل:** WorkspacePanel + بوابة المحررات (gateway.tsx) · /remote (W6a) · memory (nomic-embed-text مثبت — إصلاح L-01 من تقرير QA).
