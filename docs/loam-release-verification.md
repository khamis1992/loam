# Loam 0.5.1 — سجل التحقق والإصدار

## اتصال الخدمات

- أُصلح اتصال MCP بإضافة عميل Streamable HTTP مع الإبقاء على stdio، والتحقق الفعلي عبر initialize/list/ping/call، وإغلاق الاتصالات الفاشلة.
- المستمع السابق على3001 لم يكن يقدم MCP: طلب initialize إلى/mcp أعاد404. لم تُوقف تلك الخدمة؛ يستخدم جسر Loam المنفذ3002 على127.0.0.1.
- الجسر يشغّل الخلفيتين المثبتتين محليًا Ruflo وAgentDB. أُصلحت مخرجات بناء Ruflo المفقودة، ويهيئ AgentDB قاعدة مستقلة خاصة بـLoam دون إعادة ضبط قواعد سابقة.
- سُجلت278أداة:246منRuflo و32منAgentDB. نجح استدعاء القراءة الفعلي system_status وdb_stats، ورفض الطلب من Origin خارجي، ورفض أداة غير موجودة، واستمر منع أدوات MCP في وضع السؤال.
- الخلفيات الخارجية ليست ضمن المثبت؛ تشغيل الجسر على جهاز آخر يحتاج تثبيتها وإعداد مسارها. فحص278اسم أداة لا يعني اختبار جميع عملياتها.

## أدلة التشغيل

- فحوص TypeScript والترميز والتقييم والمنسق78/78 والاستعادة وSQLite والأنماط: ناجحة.
- فحص عزل HTTP نجح خارج قيود جلسة الاختبار بعد فشل تشغيل خادم المعاينة داخلها: ملفات ومرفقات ومعاينة منفصلة، منع traversal/junction، الطابور والإلغاء والاستئناف دون تكرار الآثار.
- واجهة الأنماط والمساعدين والصفحات الفرعية ومسار Edge الفعلي: ناجحة. بعد استعادة التصميم نجحت فحوص الواجهة والصفحات الفرعية، بما فيها تمرير الطلب وطي اللوحة وتبديل المظهر وحالة MCP المنقطعة، والعروض 320/768/1440 وRTL/LTR والتكبير 200%. نجح مسار Edge مع الحزمة النهائية: رفع ملف ثم تنفيذ أداة ونتيجة محفوظة ثم مهمة جديدة بلا ملفات السابقة.
- خدمات فعلية: الطرفية والمتصفح والذاكرة الدلالية ونموذجا السحابة والاحتياط المحلي نجحت. أُعيد اختبار خمس خدمات مع خيار--bundle؛ التقاط الشاشة سبق اختباره مرة واحدة وحذف الصورة فورًا. التفاصيل فيloam-services-final.md.
- النسخة0.5.0 المجمعة ثم الملف التنفيذي المثبت فعليًا اجتازا اختبار Electron داخل ملف مستخدم مؤقت: الاسم والإصدار وpreload، المساحات السبع، اتصالاتMCPالخمس، وكتابة ملف بطرفية أصلية.
- ثبت أن المثبت0.5.0 ينتهي برمز0، ونجح فحص manifest والتنزيل والحجم وSHA512 وblockmap5/5. استبدله الإصدار0.5.1 لاستعادة التصميم السابق بناءً على توجيه المستخدم.

## قيود الأدوات

TestSprite CLI غير مثبت، لذلك لم يُستخدم ولم تُدّعَ نتيجة منه. يمكن تثبيته ثم تشغيلtestsprite setup لاحقًا. graphify update . خرج برمز1 بلا تقرير؛ تعذر تحديث الرسم المعرفي. التحقق الفعلي هنا بواسطة اختبارات المشروع وPlaywright وطلبات HTTP محلية.

## التصميم المطلوب

التوجيه الأحدث هو استعادة ألوان وتخطيط التصميم الأصلي، ثم تحسينه، مع الاحتفاظ باسمLoam والمسميات الجديدة. لا تُستعاد صلاحيات الأدوات القديمة ولا مشاركة ملفات المهام. الإصدار0.5.1 يتضمن التصميم المصحح. نجح بناء مثبت134,093,695بايت وفحص manifest والتنزيل وSHA512 وblockmap5/5، ونجح اختبار Electron المجمّع بالتصميم المستعاد والخدمات الخمس والطرفية الفعلية.

## مراجعة بدء التشغيل

أضافت المراجعة المستقلة ثلاث إصلاحات: مقارنة معرّف ملف المستخدم ضمن هوية الخادم قبل إعادة استخدامه، وعدم استبدال مرجع خادم حي إذا تأخر اتصاله، وقراءة قائمة أدواتMCPالحالية بدل العدد المخزن عند البدء. نجح اختبار check-desktop-startup.cjs بكود Electron الفعلي مع بدائل اختبارات وساعة افتراضية: رفض ملف آخر، إعادة استخدام المطابق، بدء بطيء45ث بلا ازدواج، مهلة120ث وإغلاق المملوك فقط، وإعادة المحاولة بعد خروج مبكر.
