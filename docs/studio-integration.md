# مساحات الاستديو المدمجة

تفتح الصفحة الرئيسية والقائمة الجانبية المسارات:

- `#/studios/mobile`
- `#/studios/office`
- `#/studios/security`
- `#/studios/creative`
- `#/studios/swarm`

واجهة تطوير التطبيقات باقية على `#/modes/build`.

تُخدّم ملفات `ui/studios/` من خادم التطبيق نفسه وتُضمّن تلقائيًا في حزمة Electron عبر `ui/**/*`. لا تعتمد على خادم الموك السابق أو أي منفذ إضافي.

المعاينات والتقارير والمحاكاة داخل صفحات الاستديو أمثلة تصميمية موسومة بوضوح. زر «ابدأ مهمة فعلية» وإرسال الطلب ينقلان النص الذي كتبه المستخدم فقط إلى صفحة تحضير النمط المتاح، ثم يستخدم التطبيق مسار إنشاء المهمة والمرفقات والبث المعتاد. الربط الحالي: الجوال → build، الأوفيس → write، الأمن → build، الإنتاج → media، الأسراب → research. هذا الدمج لا يضيف محركات Rork أو Blender أو MiroFish أو فحص أمني خارجي.

يتحقق رابط الرسائل من origin ونافذة الإطار والمساحة النشطة ونوع الرسالة وحجم الطلب. مسارات الاستديو مستقلة، ويستخدم الإطار location.replace لتجنّب إدخالات سجل تصفح فرعية وسباقات التنقل.

اختبارات `npm run check:loam-ui` تغطي البطاقات الست، التنقل والتحديث والرجوع، تبويبات المساحات، تجاهل الرسائل من النوافذ الأخرى، تمرير الطلبات الخمسة إلى التنفيذ مع عدم إرسال الأمثلة، والتجاوب عند 320 و768 بكسل. فحوص typecheck وcheck:encoding ناجحة أيضًا.
