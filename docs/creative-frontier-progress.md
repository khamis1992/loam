# استديو صمّم — تقرير التنفيذ والتحقق

> تحديث لاحق: أزيلت حدود الوسائط المضمنة وأضيف التصدير الخلفي القابل للاستكمال. هذا التقرير يوثق المرحلة السابقة؛ الحالة الأحدث في `docs/creative-background-verification.md`.

آخر تحقق: 2026-10-18، النسخة المثبتة Loam 0.5.19. نطاق الخدمات الذي اختاره المستخدم: مكتبة أصول وقوالب وعناوين وترجمة ومزج صوت وإدارة التصدير، إضافة إلى المونتاج متعدد المسارات وMP4 والحفظ والاستيراد.

## المتطلبات والأدلة

| المتطلب | التنفيذ والتحقق |
|---|---|
| مونتاج متعدد المسارات | تركيب فيديو وصورة وصوت وعناوين، تقسيم ونسخ وحذف وسحب وتراجع وإعادة. اختبار الواجهة يتحقق من المقاطع والطبقات ونتيجة التركيب. |
| انتقالات | مزج متداخل وتلاشي وانزلاق؛ اختبارات بكسلات المعاينة أثناء الانتقالات وبعدها، وإطار من MP4 الناتج. |
| MP4 فعلي | توقيع ftyp وفك الفيديو للتحقق من المدة والأبعاد والمحتوى، وفك الصوت وحساب RMS. اختبار كتم صوت الفيديو مع استمرار الصوت المستقل في تصدير ثانٍ. |
| حفظ واستيراد JSON | حفظ المشروع بأصوله في المهمة، تنزيل JSON، فتح المحفوظ وإعادة استيراد الملف من الواجهة. إعادة فتح المشروع بعد إعادة تشغيل الخادم. |
| مكتبة أصول وقوالب | إعادة استخدام الأصل عند المؤشر، ثلاثة قوالب عناوين قابلة للتحرير؛ اختبار إدراج قالب وأصل والتراجع عنهما. |
| عناوين وترجمة | نصوص قابلة للتحرير واستيراد SRT إلى مسار مستقل؛ اختبار توقيت ونص الترجمة ورفض SRT غير الصالح دون تغيير المشروع. |
| مزج صوت | صوت الفيديو مع WAV مستقل ومستويات المقاطع وكتم المسارات؛ تحقق فعلي من الصوت في MP4. |
| إدارة التصدير | طابور بنسخ مشاريع مستقلة، تقدم وإلغاء وإعادة محاولة وحفظ وتنزيل. اختبار إلغاء عملية منتظرة وأخرى بدأت، وإعادة المحاولة، واستمرار نتائج التصدير بعد إعادة التحميل وإعادة تشغيل الخادم. |
| استعادة وتحرير | IndexedDB لاستعادة التعديلات غير المحفوظة بعد إعادة التحميل، وإزالة النسخة بعد الحفظ الصريح. مسطرة وتكبير 1×–8× وتجاوب بعرض 390 بكسل. |
| تثبيت وحماية المهام | نسخ 14 ملف واجهة مع نسخ احتياطية وفحص تطابق الملفات؛ بقيت 81 مهمة وإعدادات الملف الشخصي كما هي وقت التثبيت. |

## الفحوص الناجحة

- `npm run check:creative-http`: خادم المصدر والواجهة الفعلية في Edge.
- `npm run check:creative-http -- --installed`: النسخة المثبتة بخادم وبيانات اختبار معزولة. نجح مجددًا بعد إصلاحي التراجع عن إنشاء المسار وإعادة محاولة التصدير الملغى.
- `npm run check:creative-ui`: العرض ثلاثي الأبعاد والتحويلات والحركة وGLB/JSON والحفظ والتعارض والتجاوب.
- `npm run typecheck`: نجح في الفحص النهائي. فشل سابقًا أثناء تعديل متزامن لاختبار mobile ثم زال الخطأ.
- `npm run check:encoding`: نجح.

التغطية التفصيلية: `src/scripts/creative-timeline-checks.mjs` و`src/scripts/check-creative-http.ts`. الأدلة الناتجة: `output/verification/creative-timeline.mp4` و`output/verification/creative-timeline.png`. النسخة الاحتياطية الأخيرة: `output/verification/creative-tools-backup-20261018-123412`.

## حدود النطاق المُسلّم

المشروع JSON محمول بأصول مضمنة، حدّه 45 MB والمصدر حتى 30 MB. حتى 100 أصل و20 مسارًا و300 مقطع وخط زمني مدته ساعة. طابور الجلسة حتى 10 عمليات ونتيجة محفوظة حتى 50 MB؛ ما يزيد يمكن تنزيله. هذه حدود معلنة وليست اختبارات أداء عند الحدود القصوى.

التصدير محلي بالوقت الفعلي ويحتاج نافذة ظاهرة ودعم ترميز المتصفح. النتائج المحفوظة تستمر، أما العمليات المنتظرة فلا تستأنف بعد إغلاق التطبيق. الاستعادة المحلية ترتبط بمتصفح المستخدم. تخزين أصول منفصلة للمشاريع الكبيرة والتصدير الخلفي المستأنف تحسينات مستقبلية؛ لم يطلب المستخدم حدًا للحجم أو دعم مشاريع طويلة بعينها.

الخدمات المحلية التي اختارها المستخدم منفذة ومختبرة ضمن هذه الحدود. لم يُفعّل مزود توليد صور أو فيديو خارجي، ولا تفريغ كلام تلقائي. «frontier» اتجاه للجودة، وليس ادعاء تكافؤ مع منتج تجاري أو دعم كل وظائف برامج الإنتاج. دليل الاستخدام والحدود التفصيلية في `docs/creative-studio.md`.
