# Loam

مساحة عمل محلية لتنفيذ الأفكار بأدوات متخصصة وملفات مستقلة لكل مهمة.

## التشغيل

يتطلب Node.js 22.13 أو أحدث وخدمة نماذج محلية متاحة وفق `config.json`.

```powershell
npm install
Copy-Item config.example.json config.json
npm start
```

افتح عنوان الخادم المطبوع في الطرفية. لتطبيق سطح المكتب: `npm run desktop`.
لا يعيد تعديل المصدر تشغيل نسخة سابقة تعمل بالفعل؛ أغلقها بعد انتهاء مهامها ثم شغّل النسخة الجديدة.

## مساحات Loam

| المساحة | الاستخدام | الأدوات الأساسية |
|---|---|---|
| استكشف | الأسئلة والقراءة | قراءة وبحث ملفات المهمة دون تعديل |
| ابحث | البحث بالمصادر | بحث الويب وقراءة المصادر وحفظ النتائج |
| ابنِ | تطوير المشروع | الملفات وأوامر التنفيذ واختبارات المشروع والمعاينة |
| اكتب | تحرير المحتوى | محرّر Loam للمستندات وملفات النص |
| حلّل | تحليل الجداول | محلّل Loam لملفات CSV والحسابات الفعلية |
| صمّم | التصميم المتجه | لوحة Loam لإنتاج SVG والمعاينة |
| أنجز | أتمتة المتصفح | التصفح والتفاعل وتوثيق الخطوات |

لكل مساحة رابط مستقل `/#/modes/<id>`، حقول وبداءات عمل وأدوات مخصصة. الخادم يفرض قائمة الأدوات، ولا يعتمد على إخفائها في الواجهة فقط. بعض الأدوات مشتركة كأساس (مثل قراءة الملفات)، لكن الأدوات التنفيذية تختلف بين الأنماط. الأدوات الاختيارية غير المتاحة تُميّز عن الأدوات المسجّلة.

## المهام والملفات

- كل مهمة تملك مجلدًا ثابتًا داخل `<workspace>/.loam-tasks/<taskId>`.
- المرفقات تنشئ مسودة مهمة قبل الرفع وتبقى في مجلدها فقط.
- المتابعة والاستئناف يحافظان على معرّف المهمة ومساحتها ونمطها.
- قائمة الملفات والقراءة والتنزيل والمعاينة والطرفية تتطلب معرّف المهمة.
- الملفات القديمة المشتركة لا تُنقل تلقائيًا إلى المهام الجديدة؛ أرفق ما تحتاجه صراحةً.
- تُحفظ المهام ونقاط الاستئناف في SQLite. النسخ السابقة تحتفظ بمجلد بياناتها للتوافق.
- عزل الملفات وواجهاتها ليس حاوية لنظام التشغيل. نمط البناء ينفّذ أوامر بصلاحيات مستخدم الجهاز.

## التحقق

```powershell
npm run verify:loam
npm run build:server
npm run check:local-model
```

اختبارات الواجهة تتطلب Microsoft Edge. اختبار النموذج الفعلي اختياري ويستخدم نموذجًا محليًا؛ لا يدخل ضمن الاختبارات الحتمية الافتراضية. اختبارات التكامل تستخدم بيانات ومجلدات مؤقتة.

راجع [تقرير التكامل والهوية](docs/loam-integration.md) و[تقرير الخدمات](docs/loam-service-audit.md) للاختبارات والقيود والخدمات غير المتحقق منها. لا يعني ظهور تكامل اختياري في الإعدادات أنه اتصل أو اجتاز اختبار تنفيذ.

الإعدادات تدعم متغيرات `LOAM_ROOT`, `LOAM_CONFIG`, `LOAM_DATA_DIR`, `LOAM_PORT` وأسماء التوافق القديمة. بقيت أسماء التخزين القديمة والاعتمادات والبروتوكولات عند الحاجة للتوافق؛ أسماء التطبيق وأقسامه الجديدة هي Loam.
