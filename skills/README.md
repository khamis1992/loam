# المهارات (Skills)

كل مجلد هنا يمثّل مهارة تُحقن في رسالة النظام الخاصة بالوكيل، بنفس فكرة إضافات Manus
(إضافة MCP + ملف SKILL.md). الملف يُقرأ تلقائياً عند تشغيل الوكيل.

## الصيغة

`skills/<name>/SKILL.md`

```
---
name: my-skill
description: جملة قصيرة تشرح متى تُستخدم.
---

# my-skill

خطوات/قواعد تفصيلية يتبعها الوكيل عند الحاجة...
```

## نصائح
- اجعل الوصف محدداً (متى تُستخدم المهارة) لأن الوكيل يقرأ الوصف أولاً.
- ضع أمثلة أوامر/أدوات في المتن.
- لا تكتب أسراراً داخل ملفات المهارات؛ ضعها في متغيرات بيئة أو `config.json`.
- خوادم MCP تُضاف في `config.json → mcpServers` وتظهر أدواتها للوكيل بأسماء `mcp__<server>__<tool>`.

## حلقة التعلّم الذاتي (Self-improvement loop)

النظام ينمّي مهاراته بنفسه، بنفس فكرة Hermes:

- **تحميل انتقائي (Progressive disclosure)**: يُحقَن في رسالة النظام **فهرس** المهارات فقط
  (الاسم + الوصف). الوكيل يحمّل النص الكامل لأي مهارة عبر `skill_view` عند الحاجة فقط.
- **أدوات إدارة المهارات** للوكيل: `skill_list`, `skill_view`, `skill_create`, `skill_patch`, `skill_delete`.
- **مراجعة تعلّم خلفية**: بعد كل `selfImprove.reviewEvery` مهمة ناجحة تُشغَّل مراجعة تعمل
  بحلقة الوكيل نفسها وبأدوات الذاكرة/المهارات فقط، فتُنشئ مهارة جديدة أو تُحسّن موجودة أو
  تحفظ حقيقة دائمة. كل تغيير يُسجَّل في `data/learning.log`.
- **بحث الجلسات**: `session_search` يبحث في المهام السابقة (`data/db.json`).

الإعداد في `config.json`:

```json
"selfImprove": { "enabled": true, "reviewEvery": 3, "model": "", "maxSteps": 6 }
```

- `reviewEvery`: كل كم مهمة تُشغَّل المراجعة (1 = كل مهمة).
- `model`: نموذج المراجعة (فارغ = نموذج المهمة الأساسي) — يمكن وضع نموذج محلي أرخص.
- لتعطيل التعلّم الذاتي مؤقتاً: `"enabled": false`.
- **بوابة الموافقة**: `"writeApproval": true` يجعل كتابات المهارات/الذاكرة **مُعلَّقة** لا مُطبَّقة
  حتى توافق عليها من صفحة **التعلّم** (`/learning.html`) أو عبر
  `POST /api/pending/<id>/approve` / `.../reject`.
- **تنقيح الذاكرة**: تُدمَج الذكريات المتشابهة تلقائياً عند تجاوز `memory.dedupeThreshold` (تشابه
  جيبي)، ويُفرض سقف `memory.maxEntries` بإزالة الأقدم (وأولوية إزالة الوسوم `auto`) عند كل مهمة.
  تنقيح يدوي: `POST /api/memory/curate` أو زر «تنقيح الذاكرة» في صفحة التعلّم.
- **صفحة التعلّم** `/learning.html`: تعرض ما بانتظار الموافقة + سجل التعلّم (`data/learning.log`).
