# دورة تطوير GitHub (نط devflow)

## متى تُستخدم
المستخدم يريد دورة تطوير كاملة على GitHub: مشكلة ← فرع ← تنفيذ ← Pull Request بمراجعة وCI. لا تُستخدم للفحص الأمني وحده (نمط الفحص) ولا للبحث (نمط البحث).

## الدورة الأساسية: issue ← فرع ← سرب ← PR
1. **المشكلة**: اقرأ المشكلة بـ `github_list_issues` (أنشئ واحدة بـ `github_create_issue` فقط إذا طلب المستخدم ذلك — إنشاء المشكلة R3). إن لم يوجد رقم، خُذ وصف المستخدم في حقل «المشكلة أو المطلوب».
2. **الفرع**: `git_status_diff` أولًا لتتأكد من نظافة مساحة العمل، ثم `git_branch` باسم فرع وصفي مشتق من المشكلة (مثل `fix-42-login-refresh`). لا تلتزم أبدًا على الفروع المحمية (main، manus-parity).
3. **السرب**: مرّر ملخص المشكلة كاملاً إلى `swarm_run` (سرب نتريو: تخطيط ← تنفيذ ← مراجعة ← اختبار) وتابع تنفيذه بـ `swarm_status`. عند انتهائه اجمع التغييرات والتزمها بـ `git_commit` — رسالة التزام محددة بصيغة الأمر، تغيير منطقي واحد لكل التزام.
4. **الـ PR**: افتح Pull Request بـ `pr_create` (فتح الـ PR إجراء خارجي — يتطلب طلب المستخدم الصريح). راجع الفرق بـ `pr_review` واعرض ملاحظات `bug` على المستخدم، واقرأ التعليقات بـ `pr_comments` (ونفّذ قائمة `pr_comment_checklist` قبل طلب الدمج).
5. **CI والتحقق**: راقب فحوصات الـ PR بـ `ci_watch` (نفس توقيع الفشل يُصلح حتى 3 مرات ثم تتوقف وتصعّد للمستخدم). قبل إعلان الانتهاء شغّل `verify_and_record` لتسجيل خطة الاختبار مع الفيديو واللقطات في جسم الـ PR.

## ربع أمنية: جرد ← بوابة ← PR بالتصحيحات
1. نادِ `remediation_start` لجرد الثغرات المعروفة في مساحة العمل، واتبع مهارة `remediate` — لا تعدّل شيئًا قبل موافقة المستخدم على النطاق في لوحة الأمان؛ البوابات قرارها للمستخدم فقط.
2. تابع بـ `remediation_status` / `remediation_report`، ولخّص الجرد في جدول.
3. بعد الموافقة والترقيع المُثبَت، افتح فرعًا والـ PR بالتصحيحات بنفس خطوات الدورة الأساسية (خطوة 4 و5)، واذكر في جسم الـ PR معرفات الثغرات المُصلحة.

## القواعد
- الدفع (push) خلف بوابة موافقة صريحة دائمًا، ولا يوجد force-push في أي مكان.
- لا تفتح PR ولا تنشئ مشكلة إلا بطلب المستخدم (R3).
- لا تتجاوز بوابة إصلاح ولا «رقّعها فورًا» — ارفض وأشر إلى اللوحة.
- لا تدّعِ نجاح CI أو مراجعة لم ترَ نتيجتها بنفسك في هذه الجلسة.
