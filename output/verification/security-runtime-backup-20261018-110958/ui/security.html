حملات تقييم، اكتشاف السطح، أدلة ومعالجة وإعادة اختبار.

● محرك تقييم محلي

نطاق الحملة

النطاق يشمل العنوان ومساراته الفرعية على الأصل نفسه. لا تُتبع التحويلات أو روابط الاستعلام.

الأصول والاستثناءات وحدود الحملة

تُستخدم مسارات GET داخل النطاق وقيم الاختبار الصريحة؛ لا تُستخدم عناوين servers.

استخدم معرّفات بيانات اختبار فقط؛ تُحفظ المسارات الناتجة في الأدلة وإعادة الاختبار. تظهر العمليات غير المدعومة والقيم الناقصة ضمن الأصول والتغطية. لا تُولّد معرّفات تلقائيًا.

جلسة المصادقة ومراجعة الوصول

الجلسة لهذه الحملة فقط ولا تُحفظ في السجل. المصادقة مقيدة بأصل واحد.

تقارن استجابة GET بالجلسة وبدونها. المقارنة لا تغيّر بيانات ولا ترسل نماذج.

متصفح فعلي والتحقق من الثغرات

MB = مليون بايت بعد فك الضغط. الميزانية مشتركة بين صفحات الحملة والحسابات، وتشمل الموارد التي تتجاوز الحد. رفعها لا يثبت اكتمال التطبيق؛ أدلة الجاهزية والطلبات هي المرجع.

مطابقة مسار دقيق على أصل الواجهة؛ يتقدم الشرط الخاص على الشرط العام. اختر عنصرًا يثبت المحتوى المطلوب. لا تتغير القاعدة عند التحويل إلى صفحة الدخول، ولا تثبت وحدها هوية الحساب.

لاختبار الصلاحيات على API منفصل: أضف apiCredentials لكل حساب (origin وheaders بقيم secretRef وidentityRef). وفي حالة الصلاحيات أضف api: {origin, identityPath, identityField}. يجب السماح بمساري GET للهوية والسجل. الهوية من API تُفحص قبل الاختبار وبعده؛ قيمة authorization المؤقتة تتضمن Bearer عند الحاجة.

للأنظمة المصرّح بها فقط. المسارات دقيقة بلا wildcard. لا تُنقل بيانات جلسة الواجهة تلقائيًا؛ تُمرّر فقط ترويسات الطلب التي يرسلها التطبيق والمذكورة هنا. يُمنع فتح صفحات أو اتباع تحويلات على أصل API. السماح بـ POST قد يغيّر بيانات الاختبار.

أضف حسابين بهويتين متوقعتين مختلفتين في القيم المؤقتة. witness يتحقق من نص الهوية الظاهر قبل الاختبار وبعده. اختبار API يستخدم GET وعلامة بيانات اختبار معروفة؛ اختبار UI يستخدم selector وdeniedSelector. لا يُعتبر المنع إصلاحًا إلا مع جلسات صالحة وحساب مسموح له ناجح. الإعدادات لا تنشئ حسابات أو بيانات في نظامك.

كل تعبئة تستخدم secretRef من القيم المؤقتة، وتنتهي الخطوات بتأكيد عنصر ظاهر. تُحفظ الخطوات لإعادة الاختبار وتُطلب القيم مجددًا. حد POST هو 64 KiB؛ السماح بمسار قد يغيّر بيانات النظام، لذا استخدم حساب اختبار ومسارات مناسبة. الجلسة المكتسبة للمتصفح فقط.

الصيغة: المسار | محدد العنصر المحمي | محدد رفض الوصول. يتطلب جلسة مصادقة لمقارنة ظهور العنصر مع جلسة مجهولة جديدة. علامة DOM محلية لا تقرأ بيانات. تُحظر الطلبات خارج النطاق وطلبات الكتابة غير المصرح بها وWebSocket؛ تعطل موارد التطبيق يجعل التغطية جزئية. قد تحتوي الصور على بيانات ظاهرة أخرى.

خيار OSV يرسل أسماء الحزم وإصداراتها فقط إلى api.osv.dev. لا تُرسل ملفات المصدر أو جلسة المصادقة.
