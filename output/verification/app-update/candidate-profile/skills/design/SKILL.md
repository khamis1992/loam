# تصميم بصري ونظام تصميم واجهات (SVG / HTML / oklch Tokens)

## القواعد
1. أنشئ ملف HTML يحتوي التصميم بأبعاد دقيقة (مثال: 1080×1080 للمربع، 1200×630 للبانر، A4 للطباعة، أو شاشة تطبيق متجاوبة).
2. **لوحة ألوان `oklch()` متناغمة**:
   - استخدم فضاء الألوان `oklch()` لضمان تباين بصري متوازن (خلفيات كريمية/داكنة مدروسة بدل الأبيض والأسود الصارخين، مع لون أساسي `--primary` ولون تأكيد `--accent` ولون ثانوي للمجال `--brand-alt`).
3. **التزاوج الطباعي والهرمية**:
   - زاوج بين خط عنوان تحريري (`--font-display`: `Fraunces` / `Playfair Display` / `Readex Pro`) وخط نصي هندسي (`--font-sans`: `Manrope` / `Tajawal`).
   - استخدم عناصر SVG داخلية دقيقة (أشكال هندسية، تدرجات ناعمة، مسارات، مؤشرات دائرية/شريطية).
4. **التحقق**: `preview_serve` ثم `browser_open` + `browser_screenshot` للتأكد من عدم وجود عناصر متجاوزة الحدود أو ضعف في التباين.
5. سلّم: مسار الملف + جدول متغيرات `oklch()` والخطوط المستخدمة + 2-3 بدائل لونية.
