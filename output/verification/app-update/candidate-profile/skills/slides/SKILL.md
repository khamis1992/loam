# عروض تقديمية (HTML Slides)

## القواعد
1. أنشئ مجلد `workspace/<deck-name>/` ثم `index.html` (شرائح) + `styles.css`.
2. كل شريحة: `<section class="slide">` بمقاس 16:9، تنقّل بالأسهم، وترقيم.
3. التصميم: عنوان + محتوى مختصر (6 أسطر كحد)، تباين عالٍ، خط عربي واضح (`Cairo`/`Tajawal` أو system).
4. الصور: SVG/CSS فقط (بلا إنترنت) أو صور داخل المشروع.
5. **التحقق**: `preview_serve {dir:"<deck-name>"}` ثم افتح صفحة المعاينة.
6. لاحظ عدد الشرائح في النهاية مع الرابط.
7. لتصدير PPTX: اكتب `slides.md` بفواصل `---` ليمكن تحويلها لاحقاً.
