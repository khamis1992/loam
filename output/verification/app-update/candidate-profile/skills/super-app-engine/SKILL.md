# Super-App Engine (U1–U6) Workflow

Use the `super_*` tools whenever building or certifying production-grade applications:

1. **Multi-Agent App Engineering Swarm (`super_swarm`)**:
   - Coordinates `architect` -> `backend` -> `frontend` -> `verifier` to synthesize domain SQL + RLS schemas, seed live `node:sqlite` tables, generate `lib/live-client.js`, build responsive RTL/LTR `oklch()` interfaces, and issue a Zero-Defect Certificate.
2. **Semantic Code Graph & Compiler Loop (`super_code_graph`)**:
   - Inspects all imports, exports, React hooks, components, routes, and SQL tables, automatically healing missing hook imports, unexported symbols, and unregistered dependencies.
3. **Real Embedded SQLite + JWT Auth + Runtime RLS (`super_live_backend`)**:
   - Executes SQL migrations on `node:sqlite`, enforces RLS policies (`auth.uid() = user_id`), signs HS256 JWT tokens, and serves `/api/auth/*` and `/api/db/:table`.
4. **Multi-Viewport Visual Polish (`super_visual_polish`)**:
   - Audits Desktop (`1440x900`), Tablet (`768x1024`), and Mobile (`390x844`) viewports for overflow, touch targets (`>= 44px`), RTL direction, and `oklch()` tokens.
5. **4-Pillar Zero-Defect Delivery Gate (`super_quality_gate`)**:
   - Certifies the project across Code Graph, Live DB RLS, Visual Polish, and SecOps (`ZERO_DEFECT_VERIFIED`).
6. **Unified Super-Studio Workbench (`super_studio`)**:
   - Starts the unified local IDE combining Web Preview, Mobile Simulator, 3D Studio, Code Graph, Live SQLite Console, and Quality Gate.
