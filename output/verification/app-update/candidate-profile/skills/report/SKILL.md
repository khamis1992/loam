# بحث وتقرير

## القواعد
1. خطّط أولاً: اكتب 5-8 أسئلة فرعية في ردك قبل البحث.
2. ابحث عبر `web_fetch` على 3+ مصادر مختلفة، ووثّق الرابط مع كل معلومة.
3. ميّز بوضوح: حقيقة موثّقة (بمصدر) مقابل استنتاج.
4. احفظ التقرير في `workspace/reports/<topic>-<date>.md` ثم أنشئ نسخة HTML للعرض واعرضها بـ `preview_serve`.
5. البنية: العنوان/التاريخ ← الملخص التنفيذي (5 أسطر) ← النقاط الرئيسية ← الفجوات ← المصادر.
